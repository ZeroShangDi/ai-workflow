# 鲸鱼娘状态动画

来自本机安装的 `dsh-pet@0.4.1`，原始 WebM 文件直接复制，未转码。
上游：https://github.com/PC2005-cloud/dsh-pet 。保留原作者 README 和许可证于本目录。
素材使用条件以 `UPSTREAM-README.md` 为准：素材禁止商用，二创在公开渠道须署名。

`mapping.json` 是这 12 个统一展示状态的映射入口，路径相对于本目录。
每个状态一个目录，记录中文名称、建议播放方式、动画文件、大小及 SHA-256。
播放方式仅是映射元数据，本次不实现播放器、事件订阅、优先级或状态切换。

| 状态目录 | 中文状态 | 动画 | 建议方式 |
| --- | --- | --- | --- |
| idle | 待机 | 发呆碎碎念、待机呼吸休闲、悠闲哼歌、超大伸懒腰 | 轮播 |
| opening | 打开 | 元气挥手 | 一次 |
| closing | 关闭 | 女仆屈膝礼仪 | 一次 |
| connecting | 连接 | 原地踱步张望 | 循环 |
| waiting | 倾听／等待 | 轻快记录 | 循环 |
| thinking | 思考 | 思考冒泡 | 循环 |
| responding | 说话／播报 | 对屏碎碎念 | 循环 |
| error | 错误 | 垂头叹气冒汗 | 一次 |
| working | 正在执行 | 忙碌点按 | 循环 |
| producing | 生成产物 | 清点归档 | 循环 |
| completed | 执行完成 | 雀跃庆祝 | 一次 |
| attention | 需要关注 | 蓝鲸现世 | 一次 |

原 `actionGroups` 继续保留完整动作目录，不能据此假定所有动画已迁移。
这次实际迁入的文件以本目录 `mapping.json` 为准。
