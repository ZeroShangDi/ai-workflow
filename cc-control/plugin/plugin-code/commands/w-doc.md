# w-doc

文档管理方法论。覆盖需求文档、测试用例、问题记录、Bug 记录、可复用资源、决策记忆。

## 关联 Skill

- **code-doc** — 文档体系规范（base / test / issues / bugs / reuse / decision）

## 文档类型

| 类型 | 目录 | 说明 |
|------|------|------|
| 需求文档 | `docs/features/` | 功能需求、验收标准 |
| 测试用例 | `docs/features/<name>/` | 与需求文档同目录 |
| 问题记录 | `docs/issues/` | 阻塞问题、待决策事项 |
| Bug 记录 | `docs/bugs/` | 缺陷、根因、修复方案 |
| 可复用资源 | `docs/reuse/` | 组件、模块、代码片段索引 |
| 决策记忆 | `docs/discuss/` | 架构决策、方案对比、偏好记录 |

## 原则

- 文档与代码同仓库，同提交更新
- 过时文档比没文档更糟
- 增量更新优先于全量重写
