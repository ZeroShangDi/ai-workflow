# w-test

测试流程。对开发产出进行测试验证。

## 关联 Skill

- **code-test-case** — AI 生成测试用例
- **code-doc** — 测试用例文档化

## 测试维度

1. 单元测试 — 函数、模块级验证
2. 集成测试 — 模块间协作验证
3. 端到端测试 — 关键用户路径验证

## 测试流程

1. 读取 code-doc 中的测试用例文档
2. 检查测试覆盖率（行为覆盖，非行覆盖）
3. 对照测试用例逐条验证
4. 生成测试报告

## 原则

- 测试行为，不测试实现
- 先看测试失败再写实现（TDD 铁律）
- 边界和异常路径必须有测试
