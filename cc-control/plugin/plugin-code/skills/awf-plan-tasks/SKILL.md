# 任务列表生成

基于最终 WBS 树派生任务列表。两条主线：

1. **后序遍历生成任务** — 被依赖模块在前、独立模块在后
2. **同步插入门禁** — 功能级审查、模块级测试、全局文档更新

## 生成顺序（后序遍历）

按 WBS 树的**后序遍历**展开（子树全部处理完，再回到父节点）：

```
处理(节点):
  1. 对每个子节点 → 递归处理(子节点)
  2. 若节点是叶子（任务级）→ 生成一个可执行任务
  3. 若节点是功能/模块（内部节点）→ 在子树任务末尾插入对应门禁
```

- **叶子**（任务级）→ 生成普通任务
- **功能**（内部节点）→ 子树任务完成后，插入**审查任务**
- **模块**（内部节点）→ 子树任务完成后，插入**测试任务**
- **整树根** → 全部任务完成后，插入**文档更新任务**

依赖方向由树序天然表达：**被依赖/共享的子树排在树序前面，先于独立模块产出任务** —— 后序遍历保证每个任务的所有上游都先于它出现。

## 任务结构

```json
{
  "id": "T2-001",
  "title": "任务名称",
  "wbsRef": "W2-001",
  "status": "pending",
  "deps": ["T1-001"],
  "acceptance": "可验证的完成条件",
  "prompt": "执行提示词（由 awf-plan-prompt 生成）"
}
```

id 遵循编号规范 `{前缀}{级别}-{序号}`（见 w-plan 的编号规范章节）：`T`=任务，级别=树深度，序号=同级内 3 位补零递增。`wbsRef` 指向同级别的 WBS 节点（`W{级别}-{序号}`），叶子任务序号与 WBS 节点序号对齐便于溯源。门禁任务级别取其所管辖子树的叶子级别，序号排在该区块任务末尾。

## 门禁任务

| 门禁类型 | 插入位置 | 时机 | 级别/序号 |
|---------|---------|------|----------|
| 审查门禁 | 功能子树末尾 | 该功能下所有叶子任务完成后 | 取功能子树叶子级别，序号排区块末尾 |
| 测试门禁 | 模块子树末尾 | 该模块下所有功能/任务完成后 | 取模块子树叶子级别，序号排区块末尾 |
| 文档门禁 | 任务列表末尾 | 全部任务完成后（1 个） | 取整树叶子级别，序号排全局末尾 |

门禁任务自身也带 `deps`：指向其管辖子树内的全部任务（"前序任务全部完成后执行门禁"由 deps 显式表达，不依赖序号顺序）。

## 示例

```
W1-001 图片hover模块
├─ W2-001 对话能力（共享 · 被依赖）
│  ├─ W3-001 调起对话方法     → T3-001（wbsRef=W3-001）
│  └─ W3-002 对话交互         → T3-002（wbsRef=W3-002）
│  └─ 审查门禁                → T3-003（deps=[T3-001,T3-002]）
├─ W2-002 缓存能力（共享 · 被依赖）
│  ├─ W3-001 内存缓存逻辑     → T3-001（wbsRef=W3-001）
│  └─ 审查门禁                → T3-002（deps=[T3-001]）
└─ W2-003 意图识别按钮（独立）
   ├─ W3-001 按钮完整链路      → T3-001（wbsRef=W3-001）
   ├─ W3-002 异常处理          → T3-002（wbsRef=W3-002）
   └─ 审查门禁                → T3-003（deps=[T3-001,T3-002]）
（模块级）                     → 测试门禁（deps=[W2-001/002/003 全部任务+审查]）
（全局）                       → 文档门禁（deps=全部任务）
```

生成顺序即后序：对话（共享）→ 缓存（共享）→ 意图识别（独立）→ 模块测试 → 全局文档。被依赖模块的任务先产出，独立模块在后。

## 原则

- **依赖链明确**：每个任务知道它在谁之后（deps）、谁在它之后（被依赖它的任务）
- **验收可验证**：是/否可判断，不含"完善""优化"等模糊词
- **提示词随任务**：每个任务（含门禁）带有自包含执行上下文（由 awf-plan-prompt 生成），阶段断裂时 AI 能冷启动
- **门禁是任务不是检查**：门禁作为正式 task 落盘，参与状态流转，靠 deps 保证时序
- **粒度经济**：简单功能可收成模块级任务（叶子），不强制拆出功能层 —— 无功能子树则不插审查，仅插模块级测试与全局文档
