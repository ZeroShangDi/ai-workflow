# 常用包与适配场景
关键词：常用包、前端、适配场景
答案：
- `dayjs` — 轻量日期格式化与常见日期运算。
- `lodash` — 原生 API 不便表达的集合、对象和函数式工具操作。
- `i18next` — JavaScript 应用需要多语言资源管理与本地化时。
- `axios` — 需要拦截器、统一请求配置或特定传输适配的 HTTP 请求；简单请求优先考虑原生 `fetch`。

# 需要技术选型的场景
关键词：技术选型、选型场景、技术决策
答案：
- 新项目或新模块需要确定技术栈、框架或基础架构。
- 项目需要新增当前方案不具备的能力，如缓存、搜索或富文本编辑。
- 现有方案无法满足新增的功能、性能、规模或体验要求。
- 自研涉及复杂协议、算法、安全或长期维护成本。
- 需要对接外部服务、数据格式或通信协议。
- 运行平台或环境发生变化，如移动端、桌面端、服务端或离线环境。
- 有明确的体积、性能、可访问性、许可、部署或安全约束。
- 现有依赖停止维护、存在风险或已不适配，需要替换。
- 需要迁移框架、基础设施、数据库或数据格式。
- 多个可行方案会显著影响后续架构、成本或维护方式。
