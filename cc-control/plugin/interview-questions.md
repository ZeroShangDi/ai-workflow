# 前端技能检验面试题

## JavaScript 技能检验题

### 1. **概念理解与设计能力**
- **问题**："请解释闭包（closure）的概念，并设计一个实际应用场景来展示它的价值。"
- **检验点**：概念理解能力、实际应用思维、设计模式认知

- **问题**："如何解释 `this` 的绑定规则？请设计一个例子来演示不同绑定场景下的行为差异。"
- **检验点**：核心概念掌握、示例设计能力、场景分析

### 2. **性能优化能力**
- **问题**："给你一个性能低下的 JavaScript 函数，请解释你的优化思路和步骤。"
- **检验点**：性能分析能力、优化策略选择、代码重构思维

- **问题**："如何设计一个高效的 debounce 函数？请解释实现细节和边界情况处理。"
- **检验点**：算法设计能力、边界情况考虑、性能意识

## React 技能检验题

### 1. **组件设计能力**
- **问题**："请设计一个可复用的 Modal 组件，详细说明你的设计思路、props 定义、状态管理和样式策略。"
- **检验点**：组件架构设计、接口设计、状态管理策略、性能考虑

- **问题**："如何设计一个复杂的表单组件？请说明验证策略、错误处理和用户体验优化方案。"
- **检验点**：复杂组件设计、用户思维、错误处理、交互设计

### 2. **架构与性能**
- **问题**："在一个大型 React 应用中，你会如何组织组件架构？请解释你的分层策略和优化方案。"
- **检验点**：架构思维、可扩展性考虑、性能优化意识

- **问题**："React 应用出现性能问题时，你的排查思路和优化策略是什么？"
- **检验点**：问题分析能力、性能调优经验、系统思维

### 3. **状态管理**
- **问题**："对比 React Context、Redux、Zustand 等状态管理方案，请说明在什么场景下选择哪种方案，并解释原因。"
- **检验点**：技术选型能力、场景分析、深度理解

- **问题**："如何设计一个全局状态管理系统？请说明数据流设计和最佳实践。"
- **检验点**：系统设计能力、数据流理解、架构思维

## 回答指南

### 回答建议

回答这类开放式问题时，建议采用 **STAR 法则**（Situation-Task-Action-Result）：

1. **情境**：先理解问题背景和要求
2. **任务**：明确需要完成的目标
3. **行动**：详细说明你的实现思路和步骤
4. **结果**：解释预期效果和可能的改进空间

### 示例回答结构

**对于组件设计问题**：
```
首先，我会明确需求的具体场景和边界条件...
基于需求，我的设计思路是...
技术实现上，我会采用...
考虑到的挑战包括...
最终的设计方案具有以下优势...
```

**对于性能优化问题**：
```
分析性能瓶颈：从渲染、计算、网络等方面分析...
优化策略选择：针对不同瓶颈选择合适的优化方案...
具体实现：详细说明技术实现细节...
效果评估：预期达到的性能提升和测试方案...
```

### 评分维度

- **技术深度**：对核心概念的深入理解
- **思维逻辑**：分析问题的条理性和系统性
- **实践经验**：真实项目经验的体现
- **解决方案**：创新性和实用性
- **表达能力**：清晰、有条理地表达思路

### 注意事项

1. **不要只回答概念**：要将理论与实际应用结合
2. **考虑边界情况**：展示全面思考问题的能力
3. **说明取舍原因**：体现权衡思维和决策能力
4. **提及性能考虑**：展示性能意识
5. **关注用户体验**：体现用户为中心的设计思维
