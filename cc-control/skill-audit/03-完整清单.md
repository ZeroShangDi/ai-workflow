# 完整产物清单（命令 + 技能）

> 2026-08-06 · 依据：`最初构想.md`（归类框架）、`task-splitter-design.md`（拆分器设计）、`01-现状审计.md` / `02-重组方案.md`（现状与重组）
> 定位：当前 CLI 承载整套软件开发工作流，采用最新框架时所需的完整命令与技能集。

## 归类框架

```
AWF-CLI 所需     → CLI 专用（支撑运行，所有工作流共用）
workflow 所需    → 当前工作流（软件开发工作流）专用
通用所需         → 跨工作流的道与规范
```

每层产物分两类：**命令**（方向/流程/方法论）· **技能**（执行/怎么做）。

## 命令层收编建议（与现状对齐时）

- **w-commit / w-state / w-ui** 建议并入对应技能（flow-rule-git / MCP 指南 / w-design），不单列命令
- **awf-run**：自治执行侧核心，保留
- **w-tree**：并入 w-plan 展示

## 检查结论（相对初版清单）

1. **补漏 4 项**：技能图谱、awf-flow-exec-prompt、变更传播/上下文管理、测试程度执行标准（并入 code-rule-quality）
2. **拆分 3 处**：结构设计→定级/契约/WBS；任务生成→拆分/门禁；awf-flow-exec-prompt 622行→SKILL+candidates
3. **新增指南 3 个**：技能图谱（阶段路由）、道·总纲（原则映射）、awf-state MCP 指南（交互通道）
