## 逐项行动

### A. code-patterns → 解散（P0）

现状：1748 行的勾选清单，无 SKILL.md，未被任何命令加载。

- **已勾选条目**（`- [x]`）：逐条核对已并入 code-rule-style 的，删；未覆盖的，按主题并入
  - 条件/分支、异步、函数设计、类型系统、null/异常 → code-rule-style
  - 集合/数据结构、字符串、性能直觉 → code-rule-style
  - Vue/组件 的组件级条目（`v-if/v-show`、`:key`、props 单向下）→ code-rule-design（或 style 的 Vue 节）
  - VueUse / Pinia / Vite / Element Plus 源码提炼 → 迁 `docs/discuss/` 作参考资料，不留在 skill
- **未勾选条目**：与上面同步处理，不再保留「candidates」这个中间态
- 删目录，更新 CLAUDE.md

### B. awf-flow-exec-prompt → 瘦身（P0）

622 行拆为：
- `SKILL.md`（≤300）：保留「二、阶段生成规则」「三、风格铁律」「四、上下文装配」「五、状态更新模板」「六、特殊场景」+ 字典索引
- `candidates.md`：迁入「一、提示词字典」（≈340 行示例），SKILL.md 用一行引用
- 同步重写 zh-CN 为全文翻译

### C. awf-sys-spec-workflow → 精简（P1）

321 → ≤300。可裁剪点：
- 「Countdown Pause Mechanism」大段 ASCII 示意图精简
- 各 phase 详述中已被 awf-flow-exec-prompt「状态更新模板」覆盖的部分，改为引用
- 保持状态机图与关键规则不动

### D. sys-rule-skill + sys-rule-workflow → 合并（P1）

两者都管「插件自身的元规则」，边界重叠。
- **并入方向**：以 sys-rule-workflow 为主（英文正文、结构完整）
- 从 sys-rule-skill 吸收：生命周期规则（创建/更新/删除/审计清单）、命名三段式、边界检查
- 合并后名称建议 `sys-rule-skill`（管 skill+command 的完整生命周期），或保留 `sys-rule-workflow`（范围已含 command）
- 删除另一个目录；CLAUDE.md 只留一行

### E. 双语与语言规范 → 统一（P1）

- `sys-rule-skill`、`awf-flow-exec-prompt` 的**英文版正文改为英文**（当前是中文）
- 所有 zh-CN.md 补齐为 EN 全文翻译（当前 sys-rule-skill、awf-flow-exec-prompt 是摘要）

### F. code-rule-quality 版本段 → 引用（P2）

§Semantic versioning awareness 改为：「版本策略见 **flow-exec-version**」，删除内联的 major/minor/patch 表格。

### G. 注册与文档同步（P3）

- CLAUDE.md「Skills」表改为实际清单（合并后 10 个）
- 标题「10 个 skills」修正
- sys-rule-workflow snapshot 增加一行「外部依赖 skill：superpowers、figma」

## 执行顺序建议

```
1. (B) awf-flow-exec-prompt 拆字典 → 先降最大超限
2. (C) awf-sys-spec-workflow 精简
3. (A) code-patterns 解散 → 知识并入 style/design + docs/discuss
4. (D) sys-rule-skill 与 sys-rule-workflow 合并
5. (E) 双语统一 + 英文版正文翻译
6. (F)(G) quality 版本段引用 + CLAUDE.md 同步
```

每步结束跑 `sys-rule-skill` 的审计命令：
```bash
echo "=== 体积检查 ===" && for f in skills/*/SKILL.md; do lines=$(wc -l < "$f"); if [ $lines -gt 300 ]; then echo "⚠ $(dirname $f | xargs basename): ${lines}行 (超300)"; fi; done
```

> ⚠ 本方案为建议稿。A/D 涉及删除目录，需你确认后执行；B/C/E 可直接实施。
