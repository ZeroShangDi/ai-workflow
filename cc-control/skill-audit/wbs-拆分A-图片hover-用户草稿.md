# 拆分A — 图片hover 用户草稿

> 原样取自 `plugins/skills/code-plan-space.md` 的示例，未做改动。
> 结构特征：模块 → 功能（对话/缓存/三个按钮/关闭）→ 任务级叶子。

```
图片hover（模块）
  - 对话
    - 图片通用的调起对话方法
  - 缓存
    - 图片上传内存缓存逻辑，最大50张，防止图片重复上传
  - 意图识别按钮
    - 云控配置
      - 增加云控总比例，黑名单，场景云控比例
    - 按钮完整链路
      - UI，胶囊以及动画状态
      - 意图识别分析接口调用
      - 显示逻辑判断，处理云控，设置页等配置决定是否生效
      - 按钮点击后完整交互逻辑，包括，上传，存入缓存，识别，返回结果回填，点击调起对话。
      - 异常处理，包含触发风控，接口失败，缓存失败，识别失败等
    - 打点
      - 具体打点要求
  - 识图提问按钮（类似上）
  - 快速提问按钮（类似上）
  - 关闭
    - 设置页，开关，产品图，黑名单
    - 关闭组件，调用并增加关闭icon到图片hover
```

## 结构解读

- **聚合轴 = 按钮**：三个按钮（意图识别 / 识图提问 / 快速提问）是并列的功能节点，结构对称——每个含「云控配置 + 完整链路 + 打点」。
- **共享能力先上提**：对话、缓存已提为独立节点（被所有按钮共用）。
- **关闭独立**：设置页 / 开关 / 产品图 / 黑名单 + 关闭 icon 组件。
- **任务描述业务化**：写"做什么 + 约束 + 目的"（如"最大 50 张，防止图片重复上传"），可直接验收。
