# WBS 拆分对比 — 图片hover

> 对比对象：拆分A（用户草稿）vs 拆分B（能力上提）。
> 目的：找出两种组织方式的差异，收敛出一套统一标准。

## 一、先修正一个误读

拆分A 不是"没有共享"。它的共享是**分层的**：

| 共享能力 | 适配范围 | 上提层级 | 草稿中出现位置 |
|---------|---------|---------|---------------|
| 云控、设置 | 整个插件（不只图片hover） | **项目级** | 没写（超出图片hover范围） |
| 对话、上传、缓存 | 只服务图片hover | **图片hover模块级** | 挂在图片hover下（对话/缓存显式出现，上传在按钮链路里被调用） |
| 按钮特有项（云控比例/打点要求） | 单个按钮 | 不共享 | 留在按钮内 |

按钮完整链路里的"上传→存缓存→识别→回填→调对话"是**场景描述**（怎么写调用），不是实现。

## 二、核心差异：上提的层级

| 维度 | 拆分A（用户草稿） | 拆分B（能力上提） |
|------|------------------|------------------|
| 聚合轴 | 按按钮聚合（功能轴） | 按能力聚合（共享轴） |
| 上提方式 | **按适配范围分层上提** | **一刀切上提到项目级** |
| 云控/设置 | 项目级（适配全插件） | 项目级（一致） |
| 对话/上传/缓存 | **模块级**（只适配图片hover） | **项目级**（B 过度上提） |
| 按钮 | 并列功能节点，结构对称，写场景调用 | 分散，通过 deps 引用 |
| 任务描述 | 业务语言（"最大50张，防止重复上传"） | 工程语言（"实现LRU缓存，容量上限淘汰"） |

## 三、逐项对比

### 1. 云控配置

- **A**：项目级上提（草稿未写）；按钮内只留"场景云控比例"这类按钮特有项
- **B**：项目级"远程配置"模块
- **判断**：**一致**——全局云控上提到项目级，按钮特有配置项留在按钮内。B 正确。

### 2. 打点

- **A**：按钮下"具体打点要求"
- **B**：上提到项目级"打点体系"
- **判断**：**打点体系（封装）上提，打点要求（本按钮打哪些点）留在按钮内**。A 的"具体打点要求"是按钮的验收项，B 的"打点体系"是实现项，二者不冲突。

### 3. 上传 / 识别 / 对话

- **A**：对话、缓存显式挂图片hover模块级；按钮链路里"上传→存缓存→识别→回填→调对话"是场景调用
- **B**：上传服务上提到项目级；对话埋在各模式内
- **判断**：A 更准——**上传/缓存/对话只适配图片hover，上提到模块级即可，不必到项目级**。B 过度上提。且 A 点出"对话"是共享能力（图片通用调起对话方法），B 把它埋进了模式内部，A 更清晰。

### 4. 关闭

- **A**：独立节点（设置页/开关/产品图/黑名单 + 关闭 icon 组件）
- **B**：并入项目级"设置中心" + 图片识图内无关闭节点
- **判断**：A 的"关闭"分两层——**设置页/黑名单属全局（上提对），但"关闭组件 + 关闭 icon 挂到图片hover"是图片识图专属交互，应留在图片识图模块内**。B 漏了这个专属组件。

### 5. 三按钮的重复问题

- **A**：三个按钮"类似上"，结构对称
- **B**：共享能力上提后，三模式只剩独有交互
- **判断**：A 的结构对称便于独立验收（每个按钮可单独交付/测试）；"完整链路"在按钮内是场景描述（调共享能力），不是复制实现，所以不重复。**融合：按钮内写"如何组合共享能力"（场景描述），共享能力只实现一次。**

## 四、融合结论：上提的层级 = 适配范围

两种拆分不是对错，是**上提层级的选择不同**：

- **A 上提到"适配范围所在层级"**：全插件用→项目级，本模块用→模块级
- **B 一刀切提到项目级**：简单但过度

**统一标准：**

1. **上提层级由适配范围决定**——适配整个插件 → 项目级；只适配某模块 → 该模块级
2. **上提节点只写自身实现 + 提供的接口**，不写"被谁用"
3. **使用处写调用方式**——具体按钮/场景里写"调上传服务、传什么参数、怎么处理返回"
4. **按钮特有项留在按钮内**——特有云控配置、打点要求、专属组件
5. **任务描述用业务语言**——"做什么 + 约束 + 目的"，可直接验收

```
图片hover（模块）
├── 共享能力（模块级上提，只写自身实现）
│   ├── 对话：图片通用调起对话方法
│   ├── 缓存：上传内存缓存，最大50张，防重复上传
│   └── 上传链路：AI分片 + OSS + 意图识别轮询 + 风控
├── 意图识别按钮
│   ├── 云控配置（按钮特有项：场景云控比例）
│   ├── UI + 胶囊动画状态
│   ├── 显示逻辑（云控/设置页配置决定是否生效）
│   ├── 点击链路（调用上传→存缓存→识别→回填→调起对话）
│   ├── 异常处理（风控/接口失败/缓存失败/识别失败）
│   └── 打点要求（本按钮打哪些点）
├── 识图提问按钮（结构同上，特有：explain/ocr/translate 三操作）
├── 快速提问按钮（结构同上，特有：QuickAsk 状态机）
└── 关闭
    ├── 设置页/开关/产品图/黑名单（引用项目级设置中心）
    └── 关闭组件（关闭 icon 挂到图片hover，图片识图专属）

（项目级：云控、设置中心、打点体系 —— 适配全插件，独立模块）
```
