



接收一个需求，生成wbs格式的空间任务树。


解释：

空间任务树，wbs，级别等都是用来干嘛的。

级别用来决定树的深度。
拆分规则则决定树中每个节点的子节点数量，也就是树的广度。
共享节点用来处理节点的上移、下移，提炼公用模块，增强系统可维护性。
拆分步骤则用来构建树，、、

级别定义：

生态，系统，项目，模块，功能，任务。

拆分规则：

1.可以独立验证的子交付物数量 = 子节点数量
2.同一段逻辑被不同地方使用, 则上提为共享服务节点，每个节点独有的留在模式节点内。
3.共享服务节点具体被上提到什么层级需要根据适用范围决定，如果只是当前模块，则提到模块内，如果是多个模块，则提到项目级，依次类推。
4.共享节点内只负责对内的实现逻辑，对外暴露的接口定义，不负责业务方调用时的具体逻辑。业务调用的具体逻辑在对应模块任务下定义。

拆分步骤：

1.定义任务级别，如果已经到达任务级别，则停止向下拆分。
2.定义任务工作量，如果任务量过大，需要拆分。
3.定义任务依赖关系。
4.根据当前级别向下拆分，每次只拆分一个节点，只向下拆分一层。

原则：

1.默认拆分到”任务“级别，但当任务量小时也可以停止向下拆分。
2.被依赖的任务需要优先拆分，或者先定义契约，原则上尽量减少阻塞。
3.任务拆分时遵循"模块"及以上广度优先，”功能“及以下深度优先拆分原则。
4.当任务量过大上下文不足以完成所有拆分时要及时落盘，保存至 .awf/plan/wbs.json.


示例：

图片hover（模块）
  - 对话
    - 图片通用的掉起对话方法
  - 缓存
    - 图片上传内存缓存逻辑，最大50张，防止图片重复上传
  - 意图识别按钮
    - 云控配置
      - 增加云控总比例，黑名单，场景云控比例
    - 按钮完整链路
      - UI，胶囊以及动画状态
      - 意图识别分析接口调用
      - 显示逻辑判断，处理云控，设置页等配置决定是否生效
      - 按钮点击后完整交互逻辑，包括，上传，存入缓存，识别，返回结果回填，点击调起对话。
      - 异常处理，包含触发风控，接口失败，缓存失败，识别失败等
    - 打点
      - 具体打点要求
  - 识图提问按钮（类似上）
  - 快速提问按钮（类似上）
  - 关闭
    - 设置页，开关，产品图，黑名单
    - 关闭组件，调用并增加关闭icon到图片hover
