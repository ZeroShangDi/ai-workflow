# T15 死循环：任务完成但未更新状态

**时间**: 2026-08-04
**影响任务**: T15（实现 awf init 模块测试代码）
**严重度**: 高 — 阻塞后续所有任务

## 现象

T15 已重复执行 **6+ 次**（21/21 测试全部通过），但 `state.json` 中 status 仍为 `pending`。CLI 轮询发现后重复发送同一 prompt，导致无限循环。AI 每次回复「已完成」但从不调用 `awf_task_status`。从现象看 AI 甚至主动建议「继续 T16」但 CLI 不理会因为状态未变。

## 根因

AI 完成测试代码后未调用 `awf_task_status({id: "T15", status: "done"})` 更新状态。可能原因：

1. AI 发现测试代码已存在且全部通过，认为无需操作，直接返回
2. AI 没有理解「即使工作已完成，也必须更新 state.json 状态」的规则

## 建议修复

1. 在 `state-machine.md` 中强化：即使发现工作已由前置任务完成，也必须调用 `awf_task_status` 标记 done
2. 在 run.js 中增加去重：同一任务 ID 连续检测到重复发送时（如 3 次），自动跳过
