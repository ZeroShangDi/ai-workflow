# cc-work 第一版前端

本期仅接入根目录 server 已有功能，页面为 Run、任务、决策、动态任务复审、日志。复用 Figma tokens 和布局；任务、动态复审沿用已确认方向做基础列表与详情，具体设计后续调整。

不增加数据库、服务端接口、Plan 管理、设置及会话组件体系。不展示设计稿里的虚构指标。会话仍按 `/status?snapshot=1` 轮询抓屏更新；日志按 `/run/events` 增量轮询，属于当前进程内编排事件，不是完整持久化日志。

## 入口与构建

- `npm run build:web`：输出 `server/web/public`，与当前根目录 server 的默认静态路径一致。
- `npm --prefix web run dev`：默认 5173，API 经 Vite 代理。`AWF_SERVER` 可指定后端地址。
- 浏览器请求同源，不再写死后端端口。
- `/?view=run|tasks|decisions|reviews|logs&p=<项目绝对路径>`。
- `runId` 仅筛选编排事件；项目任务、决策、提案和会话抓屏均明确为项目范围。不将 runId 当作 sid 读取不存在的分片。

## 已接能力

| 页面 | 数据和操作 |
|---|---|
| Run | 会话抓屏、Run 列表、当前项目任务进度与矩阵；已有任务启动 Run、暂停/恢复调度、发送、回应 pending、打断当前响应 |
| 任务 | 当前项目全部任务、状态筛选、搜索、实际已有详情字段 |
| 决策 | requested/completed/override 记录聚合，兼容 result 嵌套；正式决策可提交替代指令；高风险动态提案可审批 |
| 动态复审 | 提案列表、状态、操作、受影响任务；现有 awaiting_approval / decision_required 审批 |
| 日志 | Run 编排事件、搜索、跟随、清屏；当前项目会话输出 |

普通决策没有通用采纳接口，因此不展示采纳按钮。已经应用后的动态任务没有复审完成接口，因此仅展示状态。未接 Agent 原始日志查询、服务端日志导出、终端打开。
