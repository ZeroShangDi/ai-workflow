# w-plan-wbs 提示词

由 CLI 在 plan 阶段 WBS 步骤调用 `claude -p` 时使用。

## 调用时机

plan 流程第 3 步：需求已规范化，开始生成 WBS 空间树。

## 输入

- 规范化后的需求描述
- 项目上下文（目录结构、技术栈）
- 已有 WBS（如果是增量）

## 输出

- WBS 空间树结构（层级：模块 → 功能 → 任务）
- 每个节点的拆解依据
- 门禁任务标记

## 约束

- 按 awf-plan-wbs 技能定义的方法论拆解
- 任务粒度：Claude Code 一次可解决的范围（1-5 文件，50-300 行）
- 不拆到最后一级，复杂度适可而止
