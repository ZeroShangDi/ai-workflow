# 执行提示词生成

为每个任务生成一个上下文完整的执行提示词，确保 awf run 阶段切换时 AI 能冷启动。

## 提示词结构

每个任务的执行提示词必须包含：

1. **当前任务** — 要做什么、为什么做
2. **上游上下文** — 前序任务完成了什么、产出了什么
3. **技术约束** — 框架、库、模式约束
4. **相关文件** — 可能涉及的文件路径
5. **验收标准** — 怎样算完成
6. **已知风险** — 可能踩的坑

## 原则

- 上下文自包含：不依赖上一阶段的对话历史
- 精准不冗余：只包含这个任务需要的，不堆砌无关信息
- 风险预警：已知的坑提前标注，避免踩坑记忆中的重复错误
