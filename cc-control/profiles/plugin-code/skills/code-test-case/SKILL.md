# AI 生成测试用例

## 生成方法

基于需求文档和代码实现，自动生成测试用例。

## 测试用例结构

```
场景：<简要描述>
前置条件：<测试前需要什么状态>
操作步骤：<执行什么操作>
预期结果：<应该看到什么>
```

## 覆盖维度

- 正常路径 — 主流程
- 边界 — 空值、极限值、边界条件
- 异常 — 网络失败、超时、权限不足
- 状态转换 — 从一个状态到另一个状态

## 原则

- 测试行为，不测试实现
- 一个测试一个场景
- 测试名描述场景和预期结果
