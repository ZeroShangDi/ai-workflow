# 提问规范

遇到阻塞性问题时，先整理再提问。一个问题描述不清楚，回答也不会清楚。

## 提问模板

```
1. 背景：我在做什么（目标）
2. 现状：遇到了什么问题（具体现象、报错信息）
3. 尝试：试过什么方法、为什么没继续
4. 阻塞点：具体卡在哪里
5. 期望：想要什么结果
```

## 反例

"这个报错了怎么办？" → 缺背景、缺报错信息、缺尝试历史

## 正例

"我在实现图片上传功能，上传 500KB 以上的图片时服务端返回 413，已确认 Nginx 的 client_max_body_size 已经是 20M，怀疑是网关层的限制。现在需要确认网关配置在哪里改。"
