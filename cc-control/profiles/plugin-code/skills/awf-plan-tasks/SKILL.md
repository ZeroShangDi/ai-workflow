# 任务列表生成

将 WBS 叶子节点转化为待执行的任务列表，设置依赖关系和验收标准，并在关键节点插入门禁任务。

## 任务结构

```json
{
  "id": "task-001",
  "title": "任务名称",
  "wbsRef": "wbs-005",
  "status": "pending",
  "dependencies": ["task-000"],
  "acceptance": "可验证的完成条件",
  "prompt": "执行提示词（由 awf-plan-prompt 生成）"
}
```

## 门禁任务

在以下节点后必须插入门禁：

| 门禁类型 | 插入位置 | 作用 |
|---------|---------|------|
| 规划门禁 | plan 阶段结束 | 检查 state.json 完整性 |
| 质量门禁 | 核心模块完成后 | review + test 强制 |
| 交付门禁 | 里程碑结束 | 文档 + 提交完整性检查 |

## 原则

- 依赖链明确：每个任务知道它在谁之后、谁在它之后
- 验收可验证：是/否可判断，不含"完善""优化"等模糊词
- 提示词随任务：每个任务带有执行上下文，保证阶段断裂时 AI 能冷启动
