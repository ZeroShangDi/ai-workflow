# w-plan

主规划流程。从一句话需求到完整规划产出的全流程方法论。

## 关联 Skill

- **awf-plan-norm** — 需求规范化（目标/边界/场景/验收标准）
- **awf-plan-wbs** — 生成 WBS 空间树（任务拆分）
- **awf-plan-tasks** — 生成任务列表（门禁任务插入）
- **awf-plan-prompt** — 提示词生成（填入任务中的执行提示词）

## 执行阶段

1. 需求归一化 → 目标、边界、场景、验收标准
2. 现状分析 → 探索代码库、识别影响范围
3. 自由讨论 → 方案对比、技术选型
4. 逐级产出 → WBS 空间树 → 任务列表 → 门禁检查

## 产出物

- `.awf/state.json` — 更新 plan 元数据 + wbs + tasks
- `docs/features/<需求名>/` — 需求文档、测试用例

## 门禁检查

每个产出步骤完成后，由 awf-plan-norm 定义的检查规则验证产出是否符合标准。
