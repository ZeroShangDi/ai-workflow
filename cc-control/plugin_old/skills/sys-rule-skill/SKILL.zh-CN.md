# Skill 管理

管理 cc-control/skills/ 下所有 skill 的完整生命周期。

## 一、命名规则

三段式：`{层级}-{角色}-{领域}`

| 段 | 可选值 | 含义 |
|----|--------|------|
| 层级 | sys / flow / code | 系统架构 / 工作流程 / 代码实践 |
| 角色 | spec / rule / exec | 规范定义 / 行为规则 / 执行工具 |
| 领域 | 一个英文单词 | 具体领域，不用缩写 |

AWF 核心 skill 前面加 `awf-`：`awf-{层级}-{角色}-{领域}`

---

## 二、体积规则

上限 300 行。超出处理顺序：**拆分 → 精简 → 外迁**

| 优先级 | 处理 |
|--------|------|
| 1 | 拆分：能否按职责拆成两个独立 skill |
| 2 | 精简：有没有可删而不影响意思的内容 |
| 3 | 外迁：纯参考资料移到 docs/discuss/ |

---

## 三、边界规则

同一个格子不能有重复 skill。两个 skill 有交集时合并或明确主从关系。

---

## 四、生命周期

- **活跃**：近 3 个里程碑被触发过
- **待清理**：连续 3 个里程碑未触发，确认后删除
- **已废弃**：功能被其他 skill 覆盖，删除

---

## 五、文件结构

```
skills/{name}/
├── SKILL.md          # 英文版（必须）
└── SKILL.zh-CN.md    # 中文版（必须）
```

---

## 六、创建

1. 确定 name — 按命名规则找格子
2. 确认格子未被占用
3. 预估体积，超 300 行先想能否拆分
4. 写英文版，再写中文版
5. 边界检查 — 是否和已有 skill 重叠
6. 注册到 CLAUDE.md

---

## 七、更新

1. 同时更新中英文两版
2. 改完复查体积
3. description 变了要同步 CLAUDE.md

---

## 八、删除

1. 确认被引用情况
2. 备份到 docs/discuss/
3. 删除目录
4. 更新 CLAUDE.md

---

## 九、审计清单

- [ ] 所有 skill 命名符合规范
- [ ] 没有超 300 行的 skill
- [ ] 没有内容重叠的 skill
- [ ] 没有连续 3 个里程碑未触发的 skill
- [ ] 每个 skill 都有中英文双版
- [ ] 所有 skill 已在 CLAUDE.md 注册
- [ ] 中文版和英文版内容同步
